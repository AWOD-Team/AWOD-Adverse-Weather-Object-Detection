# DCP 去雾参数调优指南

## 视觉问题 → 参数调整速查表

| 视觉问题 | 参数调整 | 原理 |
|---------|---------|------|
| **天空噪点/色块严重** | 增大 `t0` (0.3 → 0.5) | 防止除以接近0的传输值 |
| **阴影过深/块状伪影** | 增大 `guided_radius` (40 → 60) | 更大窗口平滑边缘 |
| **整体过暗/对比度太强** | 减小 `omega` (0.95 → 0.85) | 保留更多雾气，降低增强强度 |
| **去雾不彻底/残留雾** | 减小 `t0` (0.3 → 0.2) | 允许更激进的恢复 |
| **细节丢失/过度平滑** | 减小 `guided_eps` (1e-2 → 1e-3) | 保留更多边缘梯度 |
| **色彩不自然** | 检查是否错用 `mode="daylight"` | 应使用 `mode="standard"` |

## 核心参数详解

### 1. `t0` - 传输图下限（最关键）

**默认值**: 0.3  
**范围**: 0.05 ~ 0.6

**作用**：控制去雾强度的"安全阀"

```python
radiance = (image - light) / max(transmission, t0) + light
```

- **t0 = 0.1**（激进）：
  - ✅ 去雾彻底，远景清晰
  - ❌ 天空/雾区域噪点爆炸，色块严重
  - 适用：轻雾场景，检测器对噪声不敏感

- **t0 = 0.3**（平衡，当前默认）：
  - ✅ 噪声可控，色彩自然
  - ✅ 去雾效果仍显著
  - 适用：大多数雾天场景

- **t0 = 0.5**（保守）：
  - ✅ 噪声极低，画面稳定
  - ❌ 去雾较弱，远景仍模糊
  - 适用：浓雾场景，优先考虑稳定性

### 2. `guided_radius` - 引导滤波半径

**默认值**: 40  
**范围**: 20 ~ 80

**作用**：控制边缘感知平滑的窗口大小

- **radius = 20**（小窗口）：
  - ✅ 保留更多细节
  - ❌ 块状伪影（DCP 的 15×15 窗口产生的阶梯效应）
  
- **radius = 40**（当前默认）：
  - ✅ 平滑块状伪影
  - ✅ 保留车辆/建筑的边缘
  
- **radius = 80**（大窗口）：
  - ✅ 极度平滑，接近全局去雾
  - ❌ 可能丢失小物体细节

### 3. `guided_eps` - ���导滤波正则化

**默认值**: 1e-2 (0.01)  
**范围**: 1e-4 ~ 1e-1

**作用**：控制平滑强度 vs. 边缘保留的权衡

```python
# eps 越大，越平滑（模糊边缘）
# eps 越小，越保留边缘（但可能引入噪声）
```

- **eps = 1e-3**：强边缘保留，可能有块状伪影
- **eps = 1e-2**（当前默认）：平衡
- **eps = 1e-1**：强平滑，边缘模糊

### 4. `omega` - 去雾强度系数

**默认值**: 0.95  
**范围**: 0.75 ~ 0.95

**作用**：在粗传输图上保留一定雾气

```python
coarse_transmission = 1 - omega + omega * dark_channel
# omega=0.95: 保留 5% 的雾，避免过度增强
# omega=1.0:  完全去雾（不推荐，容易失真）
```

### 5. 光照估计参数（仅当 `local_weight > 0` 时有效）

| 参数 | 默认值 | 作用 |
|-----|-------|------|
| `light_l2` | 0.1 | L2 平滑正则化，越大越平滑 |
| `light_l1` | 0.01 | L1 稀疏正则化，越大越分块 |
| `light_iterations` | 40 | ADMM 迭代次数，越多越收敛 |

**建议**：默认使用 `local_weight=0`（纯 DCP），除非远景仍有残留雾气。

## 推荐调优流程

### Step 1: 从默认参数开始
```python
model = RetinexBDCP()  # 所有参数使用默认值
```

### Step 2: 识别主要问题
- **噪点/色块严重** → 增大 `t0`
- **阴影块状** → 增大 `guided_radius`
- **去雾不足** → 减小 `t0` 或 `omega`

### Step 3: 微调单一参数
```python
# 示例：浓雾场景，优先稳定性
model = RetinexBDCP(t0=0.4, guided_radius=50)

# 示例：轻雾场景，追求清晰度
model = RetinexBDCP(t0=0.2, omega=0.9)
```

### Step 4: 视觉验证
- 检查天空/雾区域是否有噪点
- 检查车辆/建筑边缘是否自然
- 检查整体色彩是否偏离（蓝/紫色调 = 有问题）

## 常见错误配置

❌ **错误 1: 使用 mode="daylight"**
```python
# 这会引入 sRGB ↔ 线性光转换，导致紫色色调
model = RetinexBDCP(mode="daylight")  
```
✅ **正确**：
```python
model = RetinexBDCP()  # 默认 mode="standard"
```

---

❌ **错误 2: t0 过小 + 浓雾**
```python
# 对于图中那种能见度 < 50m 的浓雾，t0=0.1 会导致噪点爆炸
model = RetinexBDCP(t0=0.1)
```
✅ **正确**：
```python
model = RetinexBDCP(t0=0.3)  # 或 0.4
```

---

❌ **错误 3: 过度依赖去雾预处理**
```python
# 现代检测器（YOLO11）对雾天已有鲁棒性
# 离线去雾可能引入更多伪影
```
✅ **正确**：
```python
# 考虑直接在原图上训练 + 数据增强
augmentations = [A.CLAHE(), A.RandomBrightnessContrast()]
```

## 实验对比建议

运行 A/B 测试，对比以下配置在你的数据集上的检测 mAP：

| 配置 | 描述 | 预期特点 |
|-----|------|---------|
| **原图** | 不去雾 | 基线，可能在浓雾区域 mAP 低 |
| **t0=0.3** | 平衡版 | 最佳折中，推荐 |
| **t0=0.5** | 保守版 | 稳定但去雾较弱 |
| **CLAHE** | 简单对比度增强 | 无色彩失真，但去雾弱 |

最终选择 mAP 最高的配置，而非视觉"最清晰"的配置。
