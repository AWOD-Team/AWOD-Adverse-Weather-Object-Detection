# night_2cls_enhanced_msrcr_v1 五折训练分析

## 1. 实验口径

- 训练日期：2026-11-26
- 数据：`awod_data/processed/night_2cls_enhanced_msrcr_v1/folds5_grouped_v1`
- 实际图片：`awod_data/processed/night_2cls_enhanced_msrcr_v1/images`
- 增强算法：MSRCR (`LowLightRetinex`)
- 增强预设：`moderate`
- 参数：`scales=[15,80,250]`、`gain=0.5`、`shadow_rolloff=20`、`contrast_stretch=true`、`denoise=mild`
- 图片/标签：2,780 / 2,780
- 五折划分：与 `night_2cls_clean_v2` 相同，分组泄漏为 0
- 模型：YOLO11n
- 训练协议：640 输入、100 epochs、batch 16、seed 0、AMP、patience 30
- 环境：Python 3.11.18、PyTorch 2.14.1、CUDA 13.4、Ultralytics 8.4.216
- 模型选择：每折使用 `val` 选择 `best.pt`
- 最终评测：每折训练结束后在 `test` 上评测一次

## 4. 类别分析

| 类别指标 | 原始基线 | MSRCR 增强 | 变化 |
| --- | ---: | ---: | ---: |
| person mAP50 | 0.6769 | 0.6815 | +0.46 pp |
| person mAP50-95 | 0.4364 | 0.4400 | +0.36 pp |
| vehicle mAP50 | 0.6040 | 0.5907 | -1.34 pp |
| vehicle mAP50-95 | 0.3948 | 0.3897 | -0.50 pp |

MSRCR 对 person 指标略有改善，但对 vehicle 指标下降，最终使整体 mAP 小幅下降。

## 5. 结论

本次 MSRCR `moderate` 增强没有在夜间五折整体检测指标上带来提升。Precision 略高，
Recall、mAP50 和 mAP50-95 均略低；其中 mAP50 下降约 `0.44` 个百分点，配对置信区间
包含 0，因此可视为接近持平且略有负向趋势。

主要收益集中在 person，主要损失集中在 vehicle。后续应针对增强参数、类别分开验证，
而不是继续仅凭整体 mAP 判断增强是否有效。
