## 四、怎么用

```bash
source ~/anaconda3/etc/profile.d/conda.sh && conda activate torch2.4_cuda12.1
D=/data/awod_data/processed/night_2cls_clean_v2/folds5_grouped_v1

# 训练第 1 折（5 折就换 fold2…fold5，其余参数保持一致）
yolo detect train model=yolo11n.pt data=$D/fold1/data.yaml \
  epochs=100 imgsz=640 batch=16 seed=0 device=0 patience=30 lr0=0.001 \
  project=runs/night_cv name=fold1

# 在留出测试集上出最终指标（必须显式 split=test）
yolo detect val model=runs/night_cv/fold1/weights/best.pt \
  data=$D/fold1/data.yaml split=test
```

## 五、三条铁律

1. **`test.txt` 只用于最终评测**。调 epoch、调学习率、挑最好的那次，只能用 `val.txt`。
   一旦用 test 的结果反过来改设置，这个数就作废。
2. **五折必须用同一套超参**（同轮数、同增强），否则 5 个成绩不可比。
3. **报告 mean ± std**，不是单个数。比较方案时用**配对比较**（同一折上比差值）。

## 六、已知局限

1. ⚠️ **各折 test 规模不均衡（340 ~ 781 张）**。原因：NOD 只有 8 个拍摄日，
   单日拍摄量差异大（164 ~ 781），而"连续拍摄必须同折"优先级最高，整天不能拆。
   `fold1` 的 test 是 781 张、train 相应偏小。报告时请注明，
   或额外报告"合并全部 test 预测"的 pooled mAP 以降低方差影响。
2. **30 张未经清洗的图**（RTTS/DAWN 夜间，不在对应 clean 集内）。
   `manifest.csv` 中 `flag=not_in_clean_set` 标记，名单见
   `/data/awod_data/processed/night_2cls_clean_v1/not_in_clean.txt`。训练前建议剔除或复核。
3. **vehicle 语义偏窄**：NOD 只标注 `car`（无 bus/truck），RTTS 的 vehicle 含 bus/motorbike。
   合并后 `vehicle` 主要指小轿车。
4. **bicycle 类已丢弃**（NOD 原有 5511 个 bicycle 框），与两类口径保持一致。
5. **路径为绝对路径**：数据集换机器或改目录名，`data.yaml` 与各 `*.txt` 会全部失效。

### NOD 清洗口径（原始 4006 → 保留 2669）

| 规则 | 阈值 | 剔除 |
| --- | --- | --- |
| 亮度过低（肉眼难分辨） | `mean_brightness < 10` | 739 |
| 目标数量太少 | `车+人框数 < 2` | 587 |
| 疑似自拍/人像摆拍 | `person 最大框面积 ≥ 0.20` 且 `框数 ≤ 3` | 11 |

剔除明细见 `nod_2cls_clean_v1/exclusion_ledger.csv`；复核用的 contact sheet 在
`nod_2cls_clean_v1/review/`。
