## 2. 数据集在新机器上如何重建

交付包含 `splits/fold*/data.yaml` 与 `train.txt / val.txt / test.txt`，**清单可复用，但路径是绝对路径**。

```bash
# 1) 把数据集放到新机器（例如 /ai/awod_data）
#    processed/night_2cls_clean_v2/{images,labels,classes.yaml,...}
#    processed/fog_2cls_clean_v1/{images,labels,...}

# 2) 重写 data.yaml 与本折清单里的绝对路径
OLD=/data/awod_data
NEW=/ai/awod_data
for f in processed/*/folds5_grouped_v1/fold*/data.yaml; do
  sed -i "s|$OLD|$NEW|g" "$f"
done
for f in processed/*/folds5_grouped_v1/fold*/*.txt; do
  sed -i "s|$OLD|$NEW|g" "$f"
done
# 3) 校验：清单里的图片是否都存在
while read f; do [ -f "$f" ] || echo "MISSING $f"; done < fold1/train.txt
```

> 五折清单本身（哪些图在哪一折）是审计过的结论，**不要重新随机划分**，否则历史指标不可比。

## 5. 纪律（写进流程，别靠记忆）

1. **改完立刻 commit + push**。服务器会消失，GitHub 上的才是留存版本。
2. **`test.txt` 只评一次**；调参、早停、选 checkpoint 一律只看 `val.txt`。
3. **五折同超参**；报告 `mean ± std`，不报单次最高值。
4. 每次训练把 `data.yaml`、`args.yaml`、`results.csv` 一起归档，不靠聊天记录存数字。
