# 数据集来源清单

> 目的：说明本项目**每个数据集从哪来**、**用什么脚本变成训练集**、**服务器到期后怎么重建**。
> 图片/标签体积大，不入 Git（见 `.gitignore`）；入库的是**清单、切分、指标**，配合本文件可在任意新机器上重建全部训练数据。
> 最后核对：2026-11-06（服务器 `/data` 租期到期前）

---

## 0. 一览

训练只用到 **3 个外部公开数据集**，外加 Ultralytics 的 COCO 预训练权重；其余数据集全部由这三者在本机用脚本派生，可完全复现。

| # | 数据集 | 天气变量 | 真实性 | 来源 | 原始规模 | 我们实际用了 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | **RTTS** | 雾 | 真实 | RESIDE（IEEE TIP 2018） | 4322 张 | 2419 → 雾天主集；79 → 夜间集 |
| 2 | **DAWN** | 雾/雨/雪/沙尘 | 真实 | DAWN (2020) + Kaggle 镜像 | 1027 张（转两类后） | 262 → 雾天主集；32 → 夜间集 |
| 3 | **NOD** | 夜间/低照度 | 真实 | NOD (BMVC 2021) | 4006 张（有标注） | 2669 → 夜间主集 |
| 4 | YOLO11n COCO 权重 | — | 预训练 | Ultralytics | — | 全部训练的初始化 |

统一口径：YOLO 两类，**`0 = vehicle`，`1 = person`**。

## 1. 外部公开数据集

### 1.1 RTTS —— 真实雾天

| 项 | 内容 |
| --- | --- |
| 全称 | RTTS，RESIDE 数据集的标准测试子集（Real-world Task-driven Testing Set） |
| 出处 | *Benchmarking Single-Image Dehazing and Beyond*，Li et al.，IEEE TIP 2018，arXiv:1712.04143 |
| 发布页 | <https://sites.google.com/view/reside-dehaze-datasets/reside-standard> |
| 我们拿到的形态 | VOC：`JPEGImages/` 4322 张 + `Annotations/` 4322 个 XML + `ImageSets/Main/` |
| 原始标注类别 | car / person / bus / truck / bicycle / motorbike（本项目归并为 vehicle + person） |
| 服务器路径 | `/data/awod_data/rtts/`（约 1.1 GB） |
| 转两类后 | `/data/awod_data/processed/rtts_2cls_v1/` 4322 张 |
| 清洗后 | `rtts_2cls_clean_v1/` **2419 张**（剔人工语义排除 1422 张、整段视频源、近重复、相邻帧） |
| 许可 | 学术研究用途；商用请回原发布页确认（RESIDE 图片部分来自网络与既有数据集） |

### 1.2 DAWN —— 真实雨 / 雪 / 雾 / 沙尘

| 项 | 内容 |
| --- | --- |
| 全称 | DAWN: Vehicle Detection in Adverse Weather Nature Dataset（Kenk & Hassaballah, 2020，arXiv:2008.05402） |
| 下载镜像 | <https://www.kaggle.com/datasets/orvile/dawn-detection-in-adverse-weather-nature>（`Fog.zip` / `Rain.zip` / `Snow.zip` / `Sand.zip`） |
| 备份镜像 | HuggingFace `Maxim37/dawn-dataset`（parquet，仅作备份，训练未用） |
| 服务器路径 | `/data/awod_data/dawn/{Fog,Rain,Snow,Sand}/`（约 279 MB 解压后） |
| 转两类后 | `processed/dawn_2cls_v1/` 1027 张，含 `subset_fog(262)` / `rain(200)` / `sand(323)` / `snow(204)` / `other(196)` |
| 清洗后 | `dawn_2cls_clean_v1/` **899 张**（去近重复 105、完全重复 22、空标签 1） |
| 雾类子集 | `foggy / haze / mist` 三类共 **262 张** → 进雾天主集 |
| 夜间子集 | 按平均亮度筛出 **32 张** → 进夜间主集 |
| 原始压缩包 MD5 | `Fog.zip 27c16c02f6cc64c2211c49a24eae3b8f`<br>`Rain.zip c367148491dd99dbc3770b3304eb7aa9`<br>`Sand.zip f2081f5a1ba80156842b78d8047e0a1d`<br>`Snow.zip f465236b46501efd215c6556b4a81705` |
| 许可 | 学术研究用途；商用请回原发布页确认 |

### 1.3 NOD —— 夜间 / 低照度

| 项 | 内容 |
| --- | --- |
| 全称 | NOD: Taking a Closer Look at Detection under Extreme Low-Light Conditions with Night Object Detection Dataset（BMVC 2021） |
| 仓库 | <https://github.com/igor-morawski/NOD>（图片 + `annotations/` 下的 COCO JSON） |
| 服务器路径 | 原图 `/data/awod_data/Nikon750/`（25 GB，4218 个 JPG，其中 **4006 张有标注**）；训练用 1280 副本 `/data/awod_data/Nikon750_1280/`（965 MB）；官方 COCO 标注 `/data/awod_data/nod_annotations/` |
| 我们用的子集 | Nikon D750 相机子集；COCO [x,y,w,h] → YOLO 转换 |
| 清洗后 | `processed/nod_2cls_clean_v1/` **2669 张**（亮度 <10 剔 739、目标 <2 剔 587、疑似摆拍剔 11；bicycle 类整体丢弃 5511 框） |
| 许可 | 学术研究用途；商用请回原仓库确认 |

## 3. 五折划分怎么来的（审计结论，**不要重新随机划分**）

| 数据集 | 脚本 | 分组依据 | 审计结果 |
| --- | --- | --- | --- |
| 雾天 `fog_2cls_clean_v1/folds5_grouped_v1` | `tools/make_grouped_fivefold.py` | RTTS 视频源前缀 / 城市×来源；DAWN 天气序列；感知哈希近重复强制同组 | 组跨折 0，每图当 test 恰一次 |
| 夜间 `night_2cls_clean_v2/folds5_grouped_v1` | `scripts/build_night_folds.py` | NOD EXIF 拍摄日（8 天）、RTTS `hv*` 视频源、DAWN 序列、phash 近重复 | 59 组整组不拆，2780/2780 各当 test 一次 |
| 近重复扫描 | `scripts/dup_scan.py`（两段式：8×8 dHash ≤6 粗筛 → 16×16 dHash ≤24 复核） | — | 雾/夜各自 `reports/*_dup.dup.json` 留存 |

五折清单与 `data.yaml` 已随交付包入库：`deliverables/*/splits/fold{1..5}/`，**可直接复用，不必重跑划分**。

## 4. 换机器后怎么重建

```bash
# 1) 下载原始数据：RTTS（RESIDE 发布页）/ DAWN（Kaggle 4 个 zip）/ NOD（GitHub 仓库 JSON + 图片）
# 2) 解压到 AWOD_DATASET_ROOT（脚本默认 /data/awod_data，可用环境变量覆盖）

# 3) 原始 VOC/COCO → YOLO 两类
python scripts/rtts_to_yolo.py            # RTTS VOC → rtts_2cls_v1
python scripts/dataset_tools.py ...       # DAWN → dawn_2cls_v1（含 fog/rain/snow/sand 子集清单）

# 4) 清洗（去低质量 / 语义排除 / 近重复）
python scripts/filter_rtts_full.py ...    # RTTS 4322 → 2419（剔除台账 reports/rtts_full_screen_final/）
python scripts/clean_nod.py ...           # NOD 4006 → 2669
python scripts/dup_scan.py --ds ... --out ...

# 5) 合并成主数据集
python scripts/merge_night_datasets.py ...    # → night_2cls_clean_v2

# 6) 分组五折
python tools/make_grouped_fivefold.py         # 雾天 folds5_grouped_v1
python scripts/build_night_folds.py           # 夜间 folds5_grouped_v1

# 7) 派生实验集（合成雾 / 去雾 / 联合）
python scripts/overnight_plan.py              # A..O 全流程，已完成阶段自动跳过
```

环境与版本见 [`交接与复现指南.md`](交接与复现指南.md)。

## 5. 考察过但**没有采用**的数据

| 数据 | 原因 |
| --- | --- |
| RESIDE **OTS** 合成雾（早期用 417 张做过 baseline） | 与 `images_1/images_2` 逐字节同源，判定为**合成雾**而非真实雾；合成→真实域偏差大，最终数据集不含 OTS。历史记录：`reports/ots417_pairs.csv` |
| 早期 testset 50 张 | 49/50 与 `images_1` 重复，属泄漏陷阱，**整体排除** |
| ACDC / Foggy Cityscapes / Foggy Driving | 语义分割/实例分割标注为主，与检测两类口径不同，未纳入 |
| Seeing Through Fog / BDD100K | 体积大、标注口径与任务不匹配，时间不足未纳入 |
| DAWN 的 rain / snow / sand | 与"雾天 + 夜间"两条主线正交，按老师建议**不同时做多天气**，仅保留雾类与夜间子集 |
