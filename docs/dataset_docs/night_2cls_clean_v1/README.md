## 重要说明

1. **有 30 张未经过清洗**。这两个夜间候选集是按平均亮度从未清洗全量中筛的，其中 30 张已被 `*_2cls_clean_v1` 剔除（人工语义排除、近重复、视频帧等）。名单见 `not_in_clean.txt`，训练前建议剔除或复核。
2. **数据量偏小**（111 张）。五折后每折测试集仅约 22 张，指标波动会很大，不适合单独出结论。建议与 NOD 夜间数据（约 4006 张）合并后再划分。
3. `images/`、`labels/` 为硬链接，**不要原地修改**。
4. 划分时需按来源分组（`hv*` 视频帧必须整段同折）。
